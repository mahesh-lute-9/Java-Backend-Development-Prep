# Java Backend Development Prep

Structured, hands-on learning log for Java Backend Development with Spring Boot — building toward interview readiness for product-based company roles.

Each folder is a self-contained, runnable project for one concept, paired with interview-style notes.

## Repo Structure

| Folder | Topic |
|---|---|
| `01_first_SpringBoot_Application` | First Spring Boot application setup |
| `02_MavenDemo` | Maven — build lifecycle, dependencies, POM |
| `03_CoreDemo` | Core Java/Spring foundational concepts |
| `04_SpringCoreDemo` | Spring Core — IoC container, Dependency Injection |
| `05_CircularDependency` | Circular dependency, bean scope, bean initialization |
| `06_BeanLifeCycle` | Spring bean lifecycle — init/destroy callbacks, `BeanPostProcessor` |
| `07_XMLConfiguration` | Spring XML-based configuration |
| `08_SpringBootCore` | Spring Boot annotations & auto-configuration |
| `09_ApplicationProperties` | `application.properties`, `@Value`, `@ConfigurationProperties`, Runner interfaces |
| `10_SpringBoot_CRUD` | Full CRUD REST API — Entity, Repository, Service, Controller, MySQL |

New folders are added as the series progresses. See [`progress.md`](./progress.md) for the running log.

## Stack

Java 17 · Spring Boot · Maven · MySQL · IntelliJ IDEA
