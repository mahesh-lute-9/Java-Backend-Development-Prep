# Java Backend Development Prep

A structured, day-by-day log of my journey learning **Java Backend Development with Spring Boot**, built with one goal in mind: getting interview-ready for product-based company roles.

This repo holds hands-on code from every topic I cover, alongside my own interview-style notes. It's less of a tutorial archive and more of a personal reference I can revisit before interviews — each folder maps to a core concept, not just "a lecture."

---

## 🎯 Why this repo exists

- Learn Spring Boot from the ground up, one concept at a time
- Build a working code example for every concept — no concept goes untouched by actual code
- Convert each concept into interview-ready notes (angles, gotchas, likely questions)
- Track progress transparently so I stay consistent and can see how far I've come

## 🗂️ Repo structure

| Folder | Topic |
|---|---|
| `01_first_SpringBoot_Application` | Setting up and running a first Spring Boot app |
| `02_MavenDemo` | Maven fundamentals — build lifecycle, dependencies, POM |
| `03_CoreDemo` | Core Java/Spring foundational concepts |
| `04_SpringCoreDemo` | Spring Core — IoC container, Dependency Injection |
| `05_CircularDependency` | Circular dependency, bean scope, bean initialization |
| `06_BeanLifeCycle` | Spring bean lifecycle — init/destroy callbacks, `BeanPostProcessor` |
| `07_XMLConfiguration` | Spring XML-based configuration |

Each folder is a self-contained runnable project for that concept.

> New folders get added as the series progresses — see `progress.md` for the live log.

## 📓 How I'm tracking this

- **Code** lives in the numbered folders above
- **Progress log** lives in [`progress.md`](./progress.md) — a running, day-by-day record of what was covered and when
- **Interview notes** (structured with gotchas + likely questions) are kept alongside each topic as I go

## 🛠️ Tools & Stack

- Java 17 LTS

- Maven
- IntelliJ IDEA
- Spring Initializr

Once the full concept series is done, the next phase is a focused **interview prep sprint** — revisiting every topic through a pure interview lens (mock questions, rapid recall, edge cases).
